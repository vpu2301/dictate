# Diarization eval methodology (sprint 14, ADR-0034)

Companion to `wer-methodology.md`; the same laptop-vs-rig discipline
applies (ADR-0019).

## What is measured

`scripts/eval/run_der.py` replays every dialogue in
`eval/conversations/v1` through the **production** diarization stream
(`dictation_service.diarization`) at the exact ADR-0013 cadence
(4 s window / 2 s stride) and scores:

- **DER** — frame-based (10 ms frames), ±250 ms collar around reference
  turn boundaries, optimal injective mapping of hypothesis labels to
  reference speakers (`scripts/eval/der_lib.py`). `UNKNOWN` hypothesis
  frames count as MISS over reference speech: honesty is cheaper than a
  wrong guess, never free. Corpus DER aggregates as total error time /
  total reference speech across 2-speaker dialogues.
- **Word-level attribution** — reference turns are split into
  pseudo-words (time ∝ token length; turn boundaries are generator
  ground truth, per-word timing inside a turn is synthetic) and each is
  attributed through the production majority-overlap merge. Strict
  accuracy counts `UNKNOWN`/pending against the score.
- **Third-voice honesty** — words spoken by the third voice must never
  receive `S1`/`S2`. This count must be **0**.
- **Latency** — wall-clock per window for VAD + embedding + clustering.
- **Mapping hint** — whether the doctor/patient inference lands, and
  whether it is correct against the fixture roles.

## Pilot bars (recorded actuals: ADR-0034)

| Metric | Bar | Measured (M5 CPU, 2026-07-26) |
|---|---|---|
| Corpus DER (2-speaker) | ≤ 0.20 | **0.029** |
| Word attribution (corpus) | ≥ 0.85 | **0.968** |
| Third-voice words labeled S1/S2 | 0 | **0** |
| Added latency per window | must keep partial p95 ≤ 1100 ms | **p95 ≤ 57 ms** |

## The corpus

`eval/conversations/v1` — 8 committed synthetic dialogues (204.5 s,
16 kHz mono s16), generated by `scripts/eval/build_conversation_fixtures.py`
(macOS `say`; distinct real TTS voice per speaker; deterministic
silences; `reference.json` carries exact turn boundaries — nothing is
hand-labeled). Includes deliberately hard cases: patient-opens
(mapping), rapid sub-second turns (stress; elevated UNKNOWN is the
designed behavior), a third voice (must land UNKNOWN), a long patient
monologue, and a «новий абзац»-mid-story fixture shared with the
voice-command gating tests.

Regenerating the corpus (`say` is not bit-stable across macOS versions)
or re-pinning the ECAPA revision requires re-baselining ADR-0034's
numbers in an amendment.

## Laptop vs rig

Laptop (Apple M5, CPU) numbers are the plumbing + relative-quality
signal. **The release gate is `make der-eval` on the A10G rig** with
the Whisper model resident — the only numbers that count for capacity
weighting (`MDX_CONVERSATION_SESSION_WEIGHT`) and the staging go/no-go
(todo.md, S14 section).

## Commands

```bash
make prepare-ecapa   # one-time: pinned model dir (fail-closed checksums)
make der-eval        # full corpus; exits non-zero if a bar fails
uv run python scripts/eval/run_der.py --corpus eval/conversations/v1 --json out.json
```
